# JIUWU_animal_hospital_schedule

JIUWU 動物醫院自動排班表。純前端網頁程式，電腦與手機瀏覽器皆可直接開啟，不需安裝、不需伺服器。

## 開始使用

1. 下載或 clone 本專案。
2. 用瀏覽器開啟 `index.html`（直接雙擊即可；或執行 `npm start` 後開啟 http://localhost:8080）。
3. 若要放到網路上讓手機開啟，可將整個資料夾部署到 GitHub Pages 或任何靜態網站空間。

所有資料（員工、每月排班表）都保存在該裝置瀏覽器的本機儲存空間，重新整理或關閉瀏覽器後仍會保留。
若要換裝置或同時在電腦與手機使用，請用頁面底部的「備份資料」下載 JSON，再於另一台裝置「還原資料」。

## 操作流程

1. **新增員工**：在「員工」區輸入姓名後按「新增員工」；點姓名旁的 ✎ 可改名，× 可刪除。刪除不會影響已生成的往期排班表。
2. **選擇月份**：右上角下拉選單，從 2026 年 9 月開始，每月排班一次。
3. **步驟一・選擇休假（可略過）**：選「休假」或「特休」後，點表格中的日期即可標記；再點一次取消。不標記的日子代表服從安排。
4. **生成排班表**：按「生成排班表」，程式依規則自動排出當月班表。
5. **步驟二・編輯**：選「上班／休假／特休／病假／事假」後點表格即可修改。
6. **儲存／取消**：「儲存」會永久保留；「取消」會復原到上次儲存的狀態（更早的儲存不受影響）。儲存後仍可再修改。
7. **匯出**：可匯出 PDF、PNG、XLSX。
8. **往期排班表**：用右上角下拉選單翻閱。

## 排班規則

| 規則 | 說明 |
| --- | --- |
| 週三全員休息 | 固定，計入上四休三。 |
| 每日出勤人數 | 預設 2 人，可在右上角調整。 |
| 連續上班上限 | 任何人在任何時間都不能連續上班超過 4 天，跨月一併計算（例如 9 月底連上 4 天，10 月 1 日就不會排班）。 |
| 上四休三 | 以週一～週日為一週，每人每週上班盡量不超過 4 天。 |
| 員工預選 | 生成前選好的「休假」與「特休」一定會被尊重。 |
| 特休、病假、事假 | 不計入上四休三：既不算上班，也不算一般休假。 |
| 休假平衡 | 扣除特休後，讓每位員工當月的一般休假天數盡量相同（因此上班天數也盡量相同）。若無法平衡，差額會記為「結餘」帶到下個月：少休的人下個月多排休，多休的人下個月少排休。 |

「結餘」欄：正值代表至今累計多休、下月會少排休；負值則相反。

若員工人數不足以維持上四休三（每日 2 人時至少需 3 位員工），程式仍會遵守「連續上班不超過 4 天」，並以紅字標示出勤不足的日子，供人工調整。

## 專案結構

```
index.html          頁面
css/style.css       樣式（天藍 + 白，其餘低飽和色）
js/scheduler.js     排班演算法（純函式，Node 也可執行）
js/app.js           介面、資料儲存、匯出
vendor/             html2canvas、jsPDF、SheetJS（PNG / PDF / XLSX 匯出）
test/               演算法測試：node test/scheduler.test.js
```
