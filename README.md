# 久吾動物醫院 自動排班表

網址：**https://nastya-777.github.io/JIUWU/**

電腦、手機瀏覽器皆可直接開啟。所有開啟此網頁的人看到並修改的都是同一份資料，變更會即時同步。

## 使用方法

### 1. 新增員工

在「員工」區輸入姓名，按「新增員工」。姓名旁的 ✎ 可改名，× 可刪除。刪除員工不會影響已生成的往期排班表。

### 2. 選擇月份

右上角「排班月份」下拉選單選擇要排的月份，從 2026 年 9 月開始，每月排一次。「每日出勤」可調整每天需要的出勤人數（預設 2 人）。

### 3. 步驟一：選擇休假（可略過）

1. 點「休息」或「特休」。
2. 點表格中想休的日期，格子會標上「休」或「特」；再點一次即取消。
3. 不選擇則視為服從安排。
4. 若某人選的休息天數比平均可休的天數多或少很多，表格下方會提示。

### 4. 生成排班表

按「生成排班表」，系統依規則自動排出當月班表。若某些日子人手不足，會以紅字標示並在下方列出。

### 5. 步驟二：編輯

點「上班」「休息」或「特休」，再點表格中的格子即可修改。下方會即時顯示是否違反規則。

- **儲存**：永久保留目前內容，之後仍可再修改。
- **取消**：復原到上次儲存的狀態，更早的儲存不受影響。
- **重新生成**：以目前的員工與休假選擇換一個排法。
- **重新選擇休假**：回到步驟一。

### 6. 匯出

「匯出…」下拉選單可選 PDF、PNG 或 XLSX。

### 7. 翻閱往期排班表

用右上角「排班月份」下拉選單切換，已儲存的月份會標示 ✓。

### 8. 備份與還原

頁面底部「備份資料」可下載全部資料的備份檔；「還原資料」可用備份檔取代目前資料。

## 排班規則

| 規則 | 說明 |
| --- | --- |
| 週三固定全員休息 | 計入上四休三。 |
| 每日出勤人數 | 預設 2 人，可調整。 |
| 連續上班上限 | 任何人在任何時間都不能連續上班超過 4 天，跨月一併計算。違規處以紅框標示。 |
| 上四休三 | 以週一～週日為一週，每人每週上班盡量不超過 4 天。 |
| 員工預選 | 生成前選好的「休息」與「特休」一定會被尊重。 |
| 特休 | 不計入上四休三：既不算上班，也不算一般休息。 |
| 休息平衡 | 扣除特休後，讓每位員工當月的一般休息天數盡量相同。若無法平衡，差額會記為「結餘」帶到下個月：少休的人下個月多排休，多休的人下個月少排休。 |

「結餘」欄：正值代表至今累計多休、下月會少排休；負值則相反。
