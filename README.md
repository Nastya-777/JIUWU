# 久吾動物醫院 自動排班表

網址：**https://nastya-777.github.io/Jiuwu/**

電腦、手機瀏覽器皆可直接開啟。所有開啟此網頁的人看到並修改的都是同一份資料，變更會即時同步。

## 使用方法

### 1. 新增員工

在「員工」區輸入姓名與入職日期，按「新增員工」。姓名旁的 ✎ 可修改姓名與入職日期，× 可刪除。刪除員工不會影響已生成的往期排班表。

特休計算方法：滿半年 3 天，滿 1 年 7 天，滿 2 年 10 天，滿 3 年 14 天，滿 5 年 15 天，滿 10 年起每年加 1 天，最多 30 天。每個年資期間重新給假，期間內未用完的不累計。

### 2. 設定國定假日

在「國定假日」區輸入日期與名稱，若當天休診請勾選「當天休診」，按「新增假日」。請在選擇休假與生成排班表之前設定好。

- 國定假日會在排班表的日期上標示「假」；勾選休診的日子全員休息。
- 每經過一個國定假日，每位員工獲得 1 天補休；補休可在假日當天或之後使用，不得早於發放日，未使用會一直保留。

### 3. 選擇週期

排班以 28 天為一個週期：第 1 週期 2026/9/1～9/28，第 2 週期 9/29～10/26，第 3 週期 10/27～11/23，以此類推。右上角先選年份、再選週期（以起訖日期顯示）；表格下方也有「上一週期」「下一週期」按鈕。開啟網頁時會直接顯示今天所在的週期。「每日出勤」可調整每天需要的出勤人數（預設 2 人）。

### 4. 步驟一：選擇休假（可略過）

1. 點「休息」「特休」或「補休」。
2. 點表格中想休的日期，格子會標上「休」「特」或「補」；再點一次即取消。
3. 不選擇則視為服從安排。
4. 若特休或補休超過可用天數、或休息天數比平均多或少很多，表格下方會提示。

### 5. 生成排班表

按「生成排班表」，系統依規則自動排出本週期的班表。若人力不足以每天兩人出勤，缺人的日子會優先安排在週二、週四，並以紅字標示。

### 6. 步驟二：編輯

點「上班」「休息」「特休」「補休」或「加班」，再點表格中的格子即可修改。下方會即時顯示是否違反規則。

- **加班**：在休息日出勤，計入時數與連續天數，並獲得 1 天補休。
- **儲存**：永久保留目前內容，之後仍可再修改。
- **取消**：復原到上次儲存的狀態，更早的儲存不受影響。
- **重新生成**：以目前的員工與休假選擇換一個排法。
- **重新選擇休假**：回到步驟一。

### 7. 匯出

先按「儲存」，再用「匯出…」下拉選單選擇 PDF、PNG 或 XLSX。尚未儲存時無法匯出。

XLSX 為每日一列的格式：日期、星期、每位員工當天的狀態（上班、休假、特休、補休、加班、店休）、當天上班人數、說明/假別備註；下方附「人員休假與補休總結」。缺人的日子以紅色標示。

### 8. 統計欄位

表格右側顯示每人本週期的上班、休息、特休、補休、加班天數，以及至週期結束的剩餘特休與剩餘補休。

### 9. 備份與還原

頁面底部「備份資料」可下載全部資料的備份檔；「還原資料」可用備份檔取代目前資料。

## 排班規則

| 規則 | 說明 |
| --- | --- |
| 週三固定全員休息 | 計入上四休三。勾選休診的國定假日同樣全員休息。 |
| 每日出勤人數 | 預設 2 人，可調整。人力不足時缺人優先安排在週二、週四。 |
| 每日出勤時數 | 每人每天 10 小時。 |
| 連續上班上限 | 任何人在任何時間都不能連續上班超過 4 天，跨週期一併計算。違規處以紅框標示。 |
| 週期出勤上限 | 每個 28 天週期（9/1～9/28、9/29～10/26……）每人出勤不超過 16 天（160 小時）。超過時以紅字提醒。 |
| 上四休三 | 以週一～週日為一週，每人每週上班盡量不超過 4 天。 |
| 員工預選 | 生成前選好的「休息」「特休」「補休」一定會被尊重。 |
| 特休、補休 | 不計入上四休三：既不算上班，也不算一般休息。 |
| 休息平衡 | 扣除特休、補休後，讓每位員工本週期的一般休息天數盡量相同。若無法平衡，差額會在下一週期自動補償：少休的人下一週期多排休，多休的人下一週期少排休。 |
